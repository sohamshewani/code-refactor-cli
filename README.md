# Code Refactor CLI

## Description

A CLI utility that scans through code repositories, identifies unused imports, and suggests refactoring opportunities while respecting code style.

## Requirements

- Python 3.8+
- pip

## Installation

```sh
pip install -e .
```

## Usage

```sh
code-refactor scan --repository path/to/repo
```
